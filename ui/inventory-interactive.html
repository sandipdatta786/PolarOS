Why Append-Only Works
The Problem: Three copies (Goa, Ship, Station) go offline for months. If you edit data (e.g., "diesel is 2,255 L"), and all three edit independently, they'll conflict when they sync.

Our Solution: Never edit. Only add events. "Officer logged: diesel consumption 129 L" is an event. A thousand copies can log independently, and when they sync, you just merge the events—no conflicts, ever.

The Math: 2,255 L is not stored. It's computed: start quantity + all received - all consumed = current. As long as events append, the answer is always correct.
